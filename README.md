# 🎶 FNAF Link Page

Página de links pessoais (estilo "link na bio") com tema de **Five Nights at Freddy's**.

## Como funciona
- 🎵 **Music Box:** a barra vai descarregando sozinha. Clique nela para dar corda (+25%), ou...
- 🎭 **System Failure:** se ela zerar, a Puppet aparece com música e animação.
- 🐻 **Nariz do Freddy:** clique no nariz do avatar para ouvir o "honk". Na 5ª vez, tem surpresa.
- 📺 Visual de monitor antigo, com linhas de varredura e fonte monoespaçada.

## Tecnologias
- HTML, CSS e JavaScript puros (um único `index.html`)
- Áudio com a tag `<audio>`
